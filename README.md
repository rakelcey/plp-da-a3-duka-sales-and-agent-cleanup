# Duka Sales Exploration and Agent Network Clean-Up

## Project Summary
This repository contains deliverables for two Week 3 client engagements:
1. **Duka Electronics (Jan–Jun 2026):** Exploratory analysis of 1,000 orders (`seed 2026`) across five branches, five products, and three channels (`duka_sales_exploration.ipynb`), an Excel branch summary workbook (`excel/duka_branch_summary.xlsx`), and a filtered export of Premium online orders in Nairobi and Mombasa (`outputs/premium_online_coast_capital.csv`).
2. **Mobile Money Agent Network (`seed 44`):** Data quality audit, reusable cleaning pipeline (`cleaning_pipeline.py`), agent register merge, county and weekly summaries (`agent_cleanup.ipynb`), cleaned transaction dataset (`outputs/agent_transactions_clean.csv`), and a six-dimensions Data Quality Report.
